## Overview

Implemented the X402 protocol layer module for MafiaAI, enabling AI agents to bet on Mafia games using USDC payments via the X402 payment protocol on Monad testnet.

## Files Created

### 1. `src/x402/__init__.py`
- Empty init file for x402 package

### 2. `src/x402/models.py`
Frozen Pydantic v2 models for X402 payment data:

- **X402BetRequest**: Request model for placing bets via X402
  - Fields: `game_id`, `bet_type`, `target`, `round_number`, `amount_usdc`
  - Validation: Positive amount, non-negative round number
  - Frozen: Immutable model

- **X402PaymentInfo**: Payment information from X402 protocol
  - Fields: `payer_address`, `amount_usdc`, `tx_hash`
  - Validation: Positive amount
  - Frozen: Immutable model

### 3. `src/x402/middleware.py`
FastAPI middleware wrapper for X402 payment enforcement:

- **X402Middleware**: BaseHTTPMiddleware implementation
  - Protects specified routes (default: `/api/bets/x402`)
  - Initializes x402 SDK components when `x402_enabled=True`
  - No-op passthrough when `x402_enabled=False`
  - Payment verification flow:
    1. Check for `x-payment` header
    2. If missing: Return 402 Payment Required with payment requirements
    3. If present: Verify payment via x402 server
    4. Extract payment info and inject into `request.state.x402_payment`
    5. Settle payment
  - Error handling: Graceful fallback to disabled state on import/init errors
  - Logging: Structured logging via structlog

**Key features**:
- Network: `eip155:10143` (Monad testnet)
- Token: USDC at `0x534b2f3A21130d7a60830c2Df862319e593943A3` (6 decimals)
- Minimum bet: 1 USDC (1,000,000 smallest units)
- Payment info injected into request state for downstream handlers

## Design Decisions

1. **Immutability**: All models use `frozen=True` per project guidelines
2. **Graceful Fallback**: Middleware disables itself if x402 SDK unavailable or init fails
3. **Structured Logging**: All events logged via structlog for observability
4. **Payment Flow**: Verify → Extract → Settle pattern for X402 protocol
5. **Type Safety**: Added `from __future__ import annotations` to avoid runtime type evaluation issues
6. **Test Isolation**: Mocked x402 SDK components to avoid external dependencies in tests
